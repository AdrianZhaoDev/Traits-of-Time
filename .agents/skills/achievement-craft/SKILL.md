# 成就系统制作指南 (achievement-craft)

本技能专门用于《时空词条：历史重开模拟器》（Traits of Time）中**现代词条 $\times$ 朝代历史时局**交互成就的设计、文案打磨与配置落地。

---

## 一、 核心定位与三大心理触发器 (Core Psychology)

成就不是枯燥的结算清单，而是驱动玩家**截图分享、社交炫耀、多周目反复刷卡收集**的核心动力源泉。所有成就必须精准击中以下三大心理机制：

1. **爆笑神吐槽与社交分享欲 (Meme & Virality)**：
   - 制造古今认知的极致反差萌与荒诞意外（如把风油精当玉露、被清凉油辣哭公堂、用打火机在雨夜冒充火德真君）。
   - 文案短促有力、神评级金句、梗点拉满，让玩家看到结局画卷的一瞬间忍不住“截图发群/发小红书发贴吧”。

2. **硬核实力派与排行榜攀比欲 (Flex & Clout)**：
   - 证明玩家的高端运营、极端运气或极限微操（如在最严苛的死局年份、极低概率、顶级四维属性下达成的改写历史奇迹）。
   - 称号威风凛凛、压迫感十足，满足硬核考据党与高玩“我有你没有”的炫耀优越感。

3. **强迫症狂喜与图鉴全收集欲 (Collection Addiction)**：
   - 明晰的阶梯感（N/R/SR/SSR），配合生动反差的五大流派走向（传奇、荒诞、平淡、搞笑、作死）。
   - 让玩家一眼看出“这个道具还有3个奇葩分支没摸出来”，自发进行下一局轮回重开。

## 二、 单词条单朝代【10个成就】黄金定额规范

每个现代词条（卡牌）进入一个特定朝代时，成就库数量**严格限定为恰好 10 个**，不多不少。10 个成就必须按稀有度与定位进行黄金比例切分：

| 稀有度 | 配额数量 | 定位与心理映射 | 对应 Category | Priority 权重区间 | 解锁门槛特征 |
| :--- | :---: | :--- | :--- | :---: | :--- |
| **N 级 (幽默/常见)** | **3 个** | **日常反差、爆笑作死、啼笑皆非的小把柄**<br>（低门槛，只要拿到道具稍微摸索或日常踩坑即可触发，负责制造初遇笑点与传播） | `anecdote` (奇物轶事) | 20 ~ 29 | 幼年误触、日常小插曲、搞笑作死或误会。 |
| **R 级 (实用/惊艳)** | **3 个** | **局部救急、信息差破局、闷声发财小能手**<br>（中门槛，需要一定属性或度过特定突发事件，展现现代生活品的局部降维打击） | `anecdote` / `milestone` | 30 ~ 49 | 避过特定灾荒、行商发家、解救关键配角、残壳变宝。 |
| **SR 级 (实力/名望)** | **3 个** | **实力封神、载入地方志、撬动官场商界格局**<br>（高门槛，要求高属性检定、完成专属短/中链或介入核心历史大事件） | `milestone` (时代里程碑) | 60 ~ 79 | 历史大事件（如大鼠疫/决堤/围城）关键贡献、官府赐牌、一代名流。 |
| **SSR 级 (逆天/传世)** | **1 个** | **终极天命、传世奇迹、改写国祚或绝版神话**<br>（极高门槛/彩蛋，复合严苛条件，最强装逼利器，社交圈顶级炫耀资本） | `milestone` 或 `life` | 80 ~ 95 | 达成苛刻的四维联合判定与极低概率分支，产生深远历史共振。 |

## 三、 文案风格规范 (四字爆款标题 + 一行神评正文)

严格遵循 [`Doc/文案设计与风格规范.md`](../../../Doc/文案设计与风格规范.md)，对标 VickScarlet/lifeRestart：

1. **成名称 (Title)**：
   - 4–7 字，自带梗点或反差感。
   - 严禁公文报告式标题（禁止：《关于风油精救治中暑的表彰》），推荐爆笑/逼格标题（如：《大明蚊见愁》、《公堂第一孝子》、《祖传帝王绿》、《阎王退票人》）。

2. **成就描述 (Text)**：
   - 单行击穿，控制在 25–45 字以内。
   - 结构公式：**【荒诞/硬核事实】+【意想不到的神转折/神吐槽】**。
   - 例：“【大明蚊见愁】浑身散发着让蚊虫自闭的霸道薄荷香，方圆十里蚊子集体绝食避难。”
   - 例：“【公堂第一孝子】误抹风油精辣哭全堂，硬是靠两斤鼻涕眼泪把知县哭得当场赔礼道歉。”
   - 例：“【阎王爷退票】本已一只脚踏入鬼门关，两滴碧绿仙液灌下，阎罗王捏着鼻子把你踹回了人间。”

## 四、 研发落地配置规范 (JSON Schema 规范)

当前数据引擎中，`achievements.json` 的标准结构如下：

```json
{
  "id": "A_MOD_{ITEM}_{KEY}",
  "name": "成就名称",
  "text": "【稀有度与定位标签】神转折文案描述。",
  "condition": {
    "op": "all",
    "conditions": [
      {
        "op": "has",
        "collection": "cards",
        "id": "CARD_MODERN_{ITEM}"
      },
      {
        "op": "has",
        "collection": "flags",
        "id": "F_MOD_{ITEM}_{KEY}"
      }
    ]
  },
  "priority": 70,
  "category": "milestone"
}
```

*注：若需在 UI 上直观展示成就稀有度，文案中推荐首句带上稀有度勋章标识（例如：`【SSR·传世还魂】...` 或 `【N·公堂孝子】...`），或通过 Priority 区间驱动前端 Badge 渲染。*

## 五、 制作自查清单 (Checklist)

每次为一个词条制作朝代成就时，必须逐项核对：
- [ ] 数量是否严格等于 **10 个**？
- [ ] 是否具备 **3 个 N 级、3 个 R 级、3 个 SR 级、1 个 SSR 级**？
- [ ] 是否覆盖了 **搞笑梗点、实力派炫耀、收集癖好奇** 三大心理触发器？
- [ ] 是否与当朝历史大事件（天灾、战乱、名将重臣、疫病）紧密融合？
- [ ] 是否至少有 1 个成就属于**残壳第二春/暮年价值**？
- [ ] 是否至少有 1 个成就属于**滑稽作死/认知错位**？
- [ ] Priority 权重是否符合三轨终局原则（未违规占用最高级主身份人生终局）？
