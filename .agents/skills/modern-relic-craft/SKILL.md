# 现代词条垂直切片与短剧式 Build 制作总则 (modern-relic-craft)

本技能专用于《时空词条：历史重开模拟器》（Traits of Time）。
核心职责：规范所有现代词条（卡牌）的内容创作与资产落地，杜绝“平淡流水账”、“单点偶发钥匙”、“纯看脸无策略”、“无脑飞升或生硬暴毙”以及“违规无法上架”五大偏差。

**生产指导基准文档**：
* 整体大纲与八大剧本规范：[`Doc/modern-relic-build-chains.md`](../../../Doc/modern-relic-build-chains.md)
* 核心文案与喜剧风格规范：[`Doc/文案设计与风格规范.md`](../../../Doc/文案设计与风格规范.md)
* 成就配额与分级规范：[`skill://achievement-craft`](../achievement-craft/SKILL.md)

## 一、 铁律红线：制作时绝对禁止的五大偏差

1. ❌ **严禁“单点偶发钥匙”**：严禁设计一张卡只在某一个事件里弹个选项，平时 90% 年份是白板。每个词条必须是一套具备常驻被动、成长链条与终局质变的完整 Build。
2. ❌ **严禁“死板绑定绝对年龄/绝对年份”**：引擎的开局年龄（3~65岁）和年份（1628~1645）是随机的！严禁写死“0~14岁必须触发第一幕”。必须采用**相对进度解耦（`after_years`）与年龄段自适应过滤（Age-Bands Mask）**。
3. ❌ **严禁“抽中即躺赢飞黄腾达”**：高级路线必须设立硬性门槛——**「核心道具 + 特定时局 + 核心属性硬指标 (如智谋 $\ge 12$) + 策略前置 Flag + D20 检定」**，策略与运气兼备。
4. ❌ **严禁“没有坏结果与暗坑”**：每个词条保留能力边界与失败分支，风险在选择前说清。死亡和灾难克制叙述，不强制配幽默死因或搞笑成就；纯文案修订不得新增事故或改变结果。
5. ❌ **严禁触碰微信小游戏审核高压线**：
   * 严禁出现造反称帝、推翻朝廷、逼宫退位（一律转化为保卫关防、救灾济民、实业兴邦、御赐免死金牌与天下第一义民）；
   * 严禁宣扬真迷信作法（一律转化为巧借自然科学常识破除假道士骗局）；
   * 严禁出现古代民族仇恨侮辱字词（一律使用中性历史词汇）。

## 二、先顺口，再精简

文风与阅读验收统一遵守 [`Doc/文案设计与风格规范.md`](../../../Doc/文案设计与风格规范.md)，不另设字数、标点、单行或笑点硬要求。

- 用自然通俗的现代中文讲清人物、动作与结果；宁可多几个字，不压成名词拼接或四字口号。
- 普通事件15—35字、重大情境或结果25—50字、选项4—10字仅为软目标；成本、风险、因果和能力边界优先。
- 趣味来自原有遭遇和反差，不为每条补吐槽或改写事实。不得把可能写成必然，也不能把局部进展写成全盘失败。
- 连同情境、选项、阶段、结果与成就检查重复。先读完整分支，再改字段；不清空字段掩盖显示层重复。
- 检查实际手机显示宽度、字号、缩放和换行；750是设计宽度，不能据此要求单行，更不能缩字、裁正文或隐藏代价。

## 三、 单个现代词条标准交付资产包（黄金量化配额）

每个现代词条的落地，必须交付**严格对齐的 7 件套资产**，缺一不可：

| 资产文件 | 配额数量 | 规范与内容要求 |
| :--- | :---: | :--- |
| **1. `cards.json`** | 1 条 | 卡牌ID、中文名、品质（N/R/SR/SSR）；说明准确交代用途和限制，字数不设硬门槛。 |
| **2. `chains.json`** | 1 条主链 (3~4节点) | 采用相对年份（`after_years: 1/3/6`）推进三幕剧情，配置中断机制（如被战火/厂卫打断）。 |
| **3. `events.json` (专属独立事件)** | 8 ~ 12 个 | 包含：4 个年龄段开局自适应事件 + 3 个 1643~1644 年极端晚开局快进决战事件 + 高阶突破事件。 |
| **4. `events.json` (职业交叉插桩)** | 4 ~ 6 个 | 在主职业（行商、从军、读书）及大历史事件中，插入持有该道具的专属反应分支。 |
| **5. `deaths.json`** | 2 ~ 3 个 | 专属死因与分支一致，清楚交代原因；克制叙述，不强制幽默或讽刺。 |
| **6. `achievements.json`** | **恰好 10 个** | 严格执行 `achievement-craft` 配额：**3 个 N 级 + 3 个 R 级 + 3 个 SR 级 + 1 个 SSR 级**。 |
| **7. 微动效/印章映射** | 1 套 | 对应博古架飞入印章、卡片高亮色系与触发像素微动效（如金光/爆烟）。 |

## 四、 四维策略门槛与网状多线化学反应设计规范
现代词条绝非孤立的脚本，必须与玩家随机到的四维属性和职业产生网状化学反应：

```
                      ┌─────────────────────────────────┐
                      │ 现代道具 (如 太阳能简易计算器)  │
                      └────────────────┬────────────────┘
                                       │
           ┌───────────────────────────┼───────────────────────────┐
           ▼ 撞上【行商】路线          ▼ 撞上【军户】路线          ▼ 撞上【文官】路线
       【经商印钞机】              【军需清账神器】            【度支大掌柜】
    三秒算清跨省漕运汇兑，      三秒核对边饷吃空饷假账，    三秒点破户部盐铁亏空，
    击败晋商徽商，买下码头。    总兵震惊，擢升军需参将。    考官惊叹，破格入度支司。
```

### 1. 高阶隐藏路线必须配置双重检定（策略 + 运气）：
* **人和门槛（策略投资）**：玩家必须有意识地在前期事件中把关键属性堆高（如【账神篇】要求 `智谋 >= 12` 且 `声望 >= 10`；【天工篇】要求 `体魄 >= 12` 且 `智谋 >= 12`）。
* **天时运气（D20 掷骰）**：
  * 在重大突破节点触发真实 D20：
  * **成功 (D20 >= 10)**：顺利迈入高光结局，名震天下；
  * **大成功 (Natural 20)**：触发隐藏高光绝版彩蛋（如皇帝亲临赐宴、免死金牌）；
  * **失败 (D20 < 10)**：属性不足强行装逼，直接跌入翻车暗坑，弹出搞笑死因与嘲讽成就。

### 2. 年龄与年份自适应逻辑：
* **开局年龄自适应（Age-Bands Mask）**：
  * 幼年 (3~10岁)：以“神童祥瑞、当玩具打脸、家庭庇护”破局；
  * 青年 (11~20岁)：以“行伍立功、集市破局、拜师入道”破局；
  * 壮年/暮年 (21岁+)：以“老农开窍、隐士出山、掌柜当家”破局。
* **极端晚年份快进（1643~1644年）**：
  * 压缩前期播种，直接空降至决战篇（如抗生素直接面临京师大疫，手电筒直接面临城下夜战），体验极限逃生短剧压迫感。

## 四、 微信小程序审核绝对红线自查清单（上线前必查）

在任何剧情或成就交付前，必须经过以下逐项机审自查：

1. **绝对禁词过滤**：
   * 严禁出现：`起义`、`造反`、`称帝`、`皇位`、`推翻朝廷`、`建国`、`登基`。
   * 规范替代：`自卫互保`、`经商致富`、`考取功名`、`开宗立派`、`御赐封赏`。
2. **封建迷信过滤**：
   * 严禁出现：`妖道`、`鬼神下凡`、`真能呼风唤雨`、`开坛作法`、`血祭`。
   * 规范替代：`巧合`、`民间戏言`、`光学视错`、`自然科学常识`。
3. **民族与社会责任**：
   * 严禁出现古代特定民族侮辱词汇（使用“关外兵马”、“边关冲突”等中性词）；
   * 终局立意必须落在：**救助乡邻、恪守诚信、勤劳致富、传承技艺、保卫家园**。
