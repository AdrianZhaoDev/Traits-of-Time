# 现代词条垂直切片制作指南 (modern-relic-craft)

本技能专用于当前项目《时空词条：历史重开模拟器》（Traits of Time）。用于为**已有或新增的现代词条**（卡牌/遗物），结合特定时代背景（如明末、秦汉、盛唐等），设计并落地具有**强蝴蝶效应、身份阶级跃迁、多风格结局**的深度剧情垂直切片。

---

## 一、 核心设计准则

1. **稀有度与爽感/剧情自由度分级及【动态乘法化学反应配额】**：
   词条的化学反应数量**严禁写死固定数值**，必须依据当前时代的事件库规模，通过**乘法动态公式**进行下限约束：
   $$\text{最低化学反应数 } N_{\text{chem}} = \lceil (\text{有效开局事件数 } E_{\text{open}} \times r_{\text{open}}) + (\text{核心朝代历史事件数 } E_{\text{era}} \times r_{\text{era}}) + (\text{通用日常/突发事件数 } E_{\text{daily}} \times r_{\text{daily}}) \rceil$$

   不同稀有度对应的事件渗透率（覆盖系数）与网状乘数标准如下：

   | 稀有度 | 开局事件渗透率 ($r_{\text{open}}$) | 核心朝代事件渗透率 ($r_{\text{era}}$) | 通用事件渗透率 ($r_{\text{daily}}$) | 消耗型退场设计 | 事业内容规划 | 核心定位与爽感尺度 |
   | :--- | :---: | :---: | :---: | :--- | :--- | :--- |
   | **N 级**<br>(生活小物件) | $\ge 50\%$ | $\ge 15\%$ | $\ge 5\%$ | 关键断舍离候选 | 短链或单发突发 | 微观反差、局部救急、信息差避坑。 |
   | **R 级**<br>(实用工业品) | $100\%$ | $\ge 30\%$ | $\ge 10\%$ | 献宝或破局候选 | 中链候选 | 技术代差撬动地方政商格局。 |
   | **SR 级**<br>(精密功能工具) | $100\%$ | $\ge 50\%$ | $\ge 20\%$ | 多种重大分支候选 | 多分支长链候选 | 撬动一省政军经脉络。 |
   | **SSR 级**<br>(战略级奇迹) | $100\%$ + 特异幼年反馈 | $\ge 80\%$ | $\ge 35\%$ | 多种逆天改命候选 | 时代级大链候选 | 时代级蝴蝶效应与重大凶险并存。 |

   表中覆盖率与分支是内容库设计目标，不要求单局遭遇所有分支，也不构成额外选择或链启动配额；任何未来现代内容必须与原生剧情共享下述整个人生选择结构。

   * **动态乘法参数规范**：
     * **$E_{\text{open}}$（开局事件池）**：当前剧本支持的所有起步事件（如幼年、少年、成年开局事件）；
     * **$E_{\text{era}}$（朝代历史大事件池）**：当前时代窗口内的标志性史实节点（如明末 1640–1645 的洛阳城破、松锦大战、开封决堤、甲申国变、弘光立朝、扬州之劫等）；
     * **$E_{\text{daily}}$（通用/突发事件池）**：季节性天灾、商贸往来、治安匪患、地方营缮、民间疫病等长周期循环池；
     * **四维交叉法则**：化学反应不能是千篇一律的通用选项；按物件、时代、年龄和属性选择合理条件（例如青年体质高参与筑坝，年长智谋高提供水文测绘）。低影响结果采用自动叙事，不因覆盖要求制造点击。
     * **N 级（日常生活小物件）**：如风油精、创可贴、打火机。
       * **爽感尺度**：不宜开局毁天灭地，侧重于“荒诞误会”、“巧妙借势”、“在信息差中赚第一桶金/避一次大坑”。
       * **影响跨度**：改变个人阶级或局部命运，主线聚焦于“神化与破产的边缘”。
     * **R / SR 级（工业制品/现代功能工具）**：如502胶水、保温杯、收废品大喇叭、净水片、多功能折叠刀。
       * **爽感尺度**：产生“技术代差/降维压制”，成为军阀争抢的圣物、官府关注的重宝或舆论杀器。
       * **影响跨度**：可撬动一府一省的政商军脉络，解锁多个阵营的专属晋升通道。
     * **SSR 级（现代文明结晶/战略级奇迹）**：如杂交水稻种子、密封抗生素板、高能聚光手电、近代数理工程速查手册。
       * **爽感尺度**：极高爽感与巨大凶险并存！一旦现世，皇帝、内阁、边关名将、起义领袖全盘震动。
       * **影响跨度**：直接改变朝廷国祚、平息或引爆全国性饥荒/疫情，引发真正意义上的历史改道（架空王朝）。
2. **【工程与产能金字塔】：轻量插桩和精品大事件**：
   原生内容与未来现代内容合计，每个完整人生严格 1–5 次成功的重大剧情选择：恰一次开局方向、至多一次随机事业转向、至多两次事业链终点、至多一次重大历史抉择。现代道具只能丰富或替换这些共享节点的路线，不能额外增加一整套选择；开局方向须先于任何死亡，幼年仍须符合依亲与学习身份。手动暂停、继续、放弃事业为可选控制，不算强制剧情选择，拒绝命令与自动 D20 阶段也不计入。
   当前生产规则仅在死亡时结局（包括寿终），成就或事业完成不授予主动谢幕资格；道具剧情不得恢复 `retire` 或强制结束人生。通用引擎可在独立夹具验证开局直接死亡，但生产开局不得跳过方向选择。

   * **A. 轻量持卡反应**：
     * 低影响日常反应不展示选项；需要不确定性时以 `automatic.outcome.next_stage_id` 进入既有真实 D20 阶段，保留属性、自然 1/20、分支结果、日志、存档和回放。使用持卡与不持卡等互斥条件保证事件及两支均适用；不要给 automatic 事件添加 `options`，不要将骰子伪称等概率选项或与 CLI `--auto` 随机代选混淆。
    * 只在共享的重大节点提供有趣或有挑战的路线，说明投入、检定、风险与可观察的长期身份、事业或结局差异；不做是/否或仅 +1 菜单，不自动支付未经授权的重大费用、启动事业、更换重大身份或替玩家采取危险主动行为。严格遵守《Doc/文案设计与风格规范.md》：全面对标 VickScarlet/lifeRestart 风格，单行击穿，充满脑洞、梗点与意外爽感，选项 3–10 字且风格反差鲜明（传统稳妥 vs 骚操作脑洞 vs 摸鱼认怂）。
    * 不枚举全排列；选择与场景最契合的年龄、属性和持卡条件，确保自动结果与选择分支各自的触发条件一致且可达。

   * **B. 精品全新独立大事件（高门槛·重大影响）**：
     * **制作方式**：为道具量身打造 Event、多阶段 Stage 或 Chain；若包含决策，必须落在共享结构既有的开局、转向、链终点或历史名额之内，不能突破上限。随机事业转向共享 `F_LIFE_DIRECTION_TURN_USED`，历史抉择共享 `F_LIFE_HISTORICAL_TURN_USED`，所有选项在阶段前写入相应标记；成功转向最多启动一条链，链中途不增加选择。
     * **准入门槛 (极高阈值)**：绝非人人可进，必须由**「持有道具 + 特定时局年份 + 严苛四维属性 (如智谋 $\ge 7$ 或声望 $\ge 6$) + 前置插桩累积的特定 Flag」**联合解锁；
     * **重大影响**：
       * **改写历史走向**：挽救崇祯帝不自缢、救活兵部重臣（如孙传庭、卢象升）、逆转松锦围城战局、提前遏制江南大鼠疫；
       * **引爆阶级裂变**：直接从平民/军户跃迁为朝廷工部侍郎、总兵官、西洋历局监正、东南海商领袖；
       * **决定性三轨终局**：重大不可逆献宝或研发可以影响终末身份与事业记录；主人生结局仍由终末状态决定，不让一次道具成就覆盖整个人生。

3. **全生命周期高度参与与蝴蝶效应五大铁律**：
   * **拒绝“单次检定后永久白板”**：
     * 严禁一张现代卡只在某一个事件中进行一次检定，成败后便沦为完全无交互的白板。
     * **全年龄段渗透覆盖**：必须在玩家人生的各阶段（幼年、少年、成年、暮年）通过海量插桩植入专属化学反应。
     * **开局强反馈**：在必须先于死亡的开局方向选择中按条件融合持卡叙事；每种起点至少两条实质不同、符合年龄身份的可用路线，不另加开局菜单。
   * **多场景常态化高频化学反应**：
     * 充分利用海量插桩，覆盖军政、商业、江湖、民生、避险、极端气候等场景（如暴雨点烽火、破庙驱野兽、阴雨烘丝绸账簿、风雪点大炮等）。
   * **道具耗尽/受挫后的“第二春”（残存机巧价值）**：
     * 现代消耗品（打火机、抗生素、电池、胶水等）用完或遇挫后，严禁直接失效废弃。
     * 必须有残壳、空瓶、内部机械零部件（如砂轮火星、玻璃瓶装水、反光外壳）在暮年、工坊、传家教学中的二次发挥。
   * **拒绝“只是属性加减”**：任何关键反应必须附带**身份（Identity/Caste）跃迁**或**重大 Flag 标记**。
   * **时代与背景深度化学反应**：必须与当时的社会矛盾（如明末辽饷、鼠疫、李自成围城、党争、卫所崩溃）紧密嵌合，不搞架空悬浮。
   * **风格多样性**：每个词条必须同时具备 **荒诞、传奇、平淡、搞笑、作死** 5 种不同走向的结局方案。
   * **拒绝“道具一次性小成就盖过整个人生”与三轨结算原则**：
     * 道具成就不允许直接占领人生主结局（Priority 绝不能普遍设为 90/100 压过内阁首辅、一代名将、高僧大儒等主身份）。
     * **三轨终局呈现规范**：
       1. **主人生结局（Life Epitaph，最高优先级 85~100）**：由玩家终末身份、社会地位、活过的年岁与时代归宿决定；
       2. **时代/事业里程碑（Career Milestones，优先级 60~80）**：记录因道具助力而取得的重大历史建树（如督造新军、开辟海贸、修历治河）；
       3. **奇物轶事/趣味成就（Relic Anecdotes，优先级 20~40）**：记录道具本身的把玩、神迹误会或荒诞小插曲，作为人生画卷的附录。
3. **【核心机制】四维交织化学反应系统 (道具 × 朝代 × 年龄 × 属性)**：
   * 现代道具绝非无脑加数值的外挂，必须与**「道具特性 $\times$ 朝代历史时局 $\times$ 人生年龄段 $\times$ 属性资质」**进行联合判定，才能解锁深层分支，形成网状蝴蝶效应。
   * **四维参数判定矩阵**：
     * **道具状态 (Item State)**：消耗型（一次性破局/献出/用尽后消失）vs 常驻型（长期持有/伴随终生持续发酵）；
     * **朝代与大事件 (Era & Timeline)**：外部大势（天时）。如明末松锦决战、开封决堤、洛阳城破、甲申国变、扬州十日等关键节点；
     * **人生年龄段 (Age Bands)**：个人生理与社会承载力（地利）。
       * *幼年 (3–10)*：依附家庭、体弱人微。若智谋/声望不足，把玩异物极易引来宗族豪右巧取豪夺（“匹夫无罪，怀璧其罪”），甚至沦为牺牲品；
       * *青年 (11–20)*：锐意进取、行动力强。体质高可充任夜不收/斥候/先锋，借道具立奇勋破格提拔；
       * *壮年 (21–45)*：职业黄金期、资源积累期。智谋高可与工匠、大儒、总督结识，尝试逆向测绘、开办作坊或军工改制；
       * *年长 (46–65)*：阅历深厚、人脉广布。声望与智谋高时可面见巡抚、六部乃至密呈帝王，作为国之重器献上，直接参与国运决策。
     * **核心属性门槛 (Attributes)**：个人驾驭能力（人和）。体质（physique）、智谋（intelligence）、财力（wealth）、声望（prestige）决定选项的成功率（DC 检定）或直接前置门槛。
   * **道具双形态生命周期设计**：
     * **形态 A：消耗型（关键抉择·破局退场）**：
       * 玩家主动在生死关头打出底牌（如战乱赎命、死罪脱险），或献于权贵/皇室换取仕途跃迁；
       * 机制上通过 `effects` 执行 `flag_remove` 移除道具，同时通过 `flag_add` 赋予持久的身份标记或事业资格；
       * 道具完成了“破局催化剂”的使命退出舞台，后续人生完全由该事件引发的社会地位新分支接管。
     * **形态 B：常驻型（长期持有·持续共振）**：
       * 玩家选择自持、保密或作为母本研发，道具 Flag 终身保留；
       * 渗透到后续不同年份的历史大事件与突发危机中，日常反应自动呈现，仅关键取舍提供高阶分支选项；
       * 伴生负面暗流：长期持有异宝会随时间推移积累“窥伺度”，引来厂卫、江洋大盗或同行诬告等专属连环危机。

4. **文案风格与合规红线**：
   * 必须严格遵守 [`Doc/文案设计与风格规范.md`](../../../Doc/文案设计与风格规范.md)。
   * **白话、精炼、幽默神吐槽、拒绝文青文绉绉**。
   * **政治、民族定性与血腥审核红线绝不触碰**（不挑起古代民族对立、不宣扬算命真迷信、死因滑稽荒唐或客观交代）。

## 二、 制作流程三步法

### 第一阶段：需求对齐与档案初始化
1. 确定**词条名称、当前稀有度、目标时代（默认 `ERA_MING_END` 崇祯末年）**。
2. 提炼词条的 **3 大核心物理特性**（如打火机：无需火石瞬燃、塑料透明外壳、气压燃料有限）。
3. 提炼古代各阶层（军户、流民、士绅、商贾、权贵）眼中的 **认知错位（它像什么神物？）**。

### 第二阶段：大纲生成（供用户审核与挑选）
在正式编写 JSON 数据前，必须先输出结构化大纲，包含：
1. **全生命周期渗透矩阵**：
   * **开局初遇（幼年/少年/成年）**：说明各开局的专属反馈及如何融入必选的共享方向；低影响反应自动发生，不另增起步菜单。
   * **常态化学反应事件库**：至少 4 个结合时代痛点（气候、战乱、疫病、饥馑、经商）的持卡专属事件与互动机制。
2. **三幕式主线任务链演进**：
   * **第一幕·神迹降世**：产生第一次认知冲击，完成初步身份跃迁或积累第一桶金。
   * **第二幕·危机/分水岭（关键蝴蝶节点）**：道具损耗、势力觊觎、朝廷征召或同行拆台；有真实取舍时嵌入共享重大选择节点，其他进展以真实 D20 自动处理。
   * **第三幕·终局收束**：给出 5 种风格结局的简要走向与核心神吐槽文案。
3. **余生与残存价值设计**：
   * 消耗殆尽或年迈退隐后，道具残留物（如空盒、金属构件、机械传动）在暮年如何继续作为传家宝或授徒启蒙道具发挥余热。
4. **输出格式**：呈报给用户，列出 A/B 路线差异，待用户确认或微调大纲。
### 第三阶段：工程资产落地与校验
用户审核通过后，同步落位项目核心资产库（`assets/resources/data/<era_id>/`）：
1. **`cards.json`**：确认或补充词条配置与专属 Tags。
2. **`chains.json`**：设计词条专属多节点任务链（配置相对启动年的 `after_years`、阶段推进）；与原生开局和转向共用启动机会，中途自动执行，终点决策计入两次链终点上限。
3. **`events.json`**：使用事件根级 `condition` 检查卡牌 / Flag，按 Schema 分别配置 `interaction: automatic` 的 `outcome`，或共享重大节点的 `interaction: choice`、`options` 及阶段检定；自动事件不能附带 `options`。有骰子时记真实骰值与结果，恢复及回放保持一致。
4. **`deaths.json`** & **`achievements.json`**：落位作死死因与专属成就。
5. **验证闭环**：
   * 运行格式与依赖校验：`npm run validate:content -- --content assets/resources/data/<era_id>`
   * 运行测试：`npm run test:content`
   * 本地 CLI 试跑及模拟：普通交互与显式 `--auto` 分开检查；normal、cautious、risky 和事业发展策略各至少 100 个完整人生种子，逐局核对成功剧情选择 1–5 次、各起点方向可用、长期分支有可观察后果，抽查自动 D20 不同结果及恢复回放。报告目录必须不存在；真人时长另行测量。

## 三、 大纲标准输出模板

在为某个词条起草大纲时，采用以下标准模板呈现：

```markdown
# 【词条制作大纲】[词条名] × [时代名]
```
