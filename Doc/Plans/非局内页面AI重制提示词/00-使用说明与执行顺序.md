## 怎么执行

- 01～07 各有一个完整执行代码块，08 每项也可单独复制。它们是后续任务指令；本次设计批准不等于批准实施、批量生产、调用外部服务或付款。只有另行委托相应阶段时才执行，未授权时只整理无请求计划及获准本地材料。
- 顺序为 01→02→03→04→05→06→07。02 验证 A 的 Canvas 还原与可操作性，不提出另一轮 A／B／C 选择。Canvas 样板、单件美术和音频仍须各自验收，不能用设计批准替代媒体或平台批准。
- 03 美术与 05 音频在各自输入及授权齐备后可并行；声音接线仍依赖界面上下文。首批制作目标是 IMG-BG-01 与 MUS-01；未指定供应商及预算／额度时不调用，也不以已登录 CLI 或已有密钥替代授权。
- 750 是逻辑设计宽，不是 CSS 像素或位图／DPR。背景母版目标 1080×1920，运行时等比适配与裁切，不能非等比拉伸。
- 结果按既有阶段路径原位维护，不另建历史、备份或候选规范。计划路径不代表文件已存在；`local/` 的制作材料不替代 `public/` 生产资源与 `licenses/` 来源证据。不得篡改原始截图、测量或许可记录来声称新验证。

## A 的共同执行口径

奶油纸 `#FFF9E9`、墨字 `#302826`、辅字 `#67594C`、面板 `#FFFDF5`；番茄红 `#BF3527` 用于展示标题、品牌和警告，**主 CTA 使用亮黄 `#FFDA58`＋墨字＋墨线＋短硬偏移阴影**。悬停／已选辅助底 `#FFF0AC`；红色状态加深为 `#A42B21`，红底配 `#FFF9E9`；装饰分隔线 `#D8C899` 不能单独承担控件边界；焦点专用 `#196C8A` 即时显示；禁用底 `#E4DDD0`。

用挺直粗黑体和清楚的无衬线正文，平涂明亮的明代市井漫画、简单轮廓、局部粗墨线。首页可有一个品牌视觉锚点和 2–3 CSS px 的局部套印错位；长文面板安静，不为每行都加粗框、阴影、气泡或拟声。喇叭只是品牌，不是固定开局物品或奖励。默认无环境微尘、光束或视频。

实际 Canvas 缩放后正文以约 16 CSS px 以上为目标，辅助字不低于 12 CSS px，进度警告目标 13–14 CSS px；正常文字对比 4.5:1，大字和有意义边界 3:1。点击区至少 44 CSS px、相邻间距至少 8 CSS px，逻辑点击阈值为 `ceil(44*750/实际CanvasCSS宽度)`（360→92、390→85）。短屏先减插画和装饰间距，再滚动，不缩字、截字或挤掉控件。

## 保护边界

重做：首页、身份、开局三选一、成就、统计、声音、事业管理四页、物品详情、终局。管理／详情／设置等目标弹层从局内打开时仍在范围内，**底下的局内画面不改**。

不改：人生推演主画面、HUD、历史折页、博古架本体、推进、重大抉择、检定及实际局内特效、音乐、地区声。整体主规范包含这些界面的未来目标风格，但本提示词包不据此扩大实施范围。原生加载／失败提示保留；共享物品图、`tap`、`life`／终局曲目、UI 原语不得原位全局替换。

玩法、生产 JSON、内容 ID、概率、持久化均保持原样：本机完成记录和声音设置延续既有保存方式，未完成的人生仍仅在内存中；不新增继续人生、商店、登录、奖励、槽位、默认家当或强制喇叭。当前选卡只切换选中目标，不能点击同卡取消；SFX-07 继续仅预留。
