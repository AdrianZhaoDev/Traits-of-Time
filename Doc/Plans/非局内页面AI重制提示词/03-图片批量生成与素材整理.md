# 03-图片批量生成与素材整理

## 使用方式

将下方代码块完整复制给能访问本项目的编程／设计 AI，仅执行另行委托的本阶段。本轮只覆盖文档，不生成、上传或检查图片。已批准 A 不等于已批准批量生产；视觉主规范为[整体 UI 风格方案](../../UI整体风格方案.md)，动效见[配套规范](../../动效与微交互制作规范.md)。
