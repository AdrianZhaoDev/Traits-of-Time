# 06-资源接入与发布整理

## 使用方式

仅在另行委托接入阶段时复制执行。本轮只覆盖文档，不接入文件、不执行构建、不上传发布。A 已获选，[整体 UI 主规范](../../UI整体风格方案.md)和[动效配套规范](../../动效与微交互制作规范.md)是依据；资源、许可与平台状态仍须真实核对。
