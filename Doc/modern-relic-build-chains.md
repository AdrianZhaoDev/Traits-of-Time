## 一、 为什么必须重构？—— 从“偶发钥匙”到“短剧式 Build 引擎”

### 1. 过去系统致命病因
1. **“单点偶发钥匙”病**：抽中道具后，只有在极少数特定年份碰到了特定事件才弹出一个选项（如开高亮手电），平时 90% 的年份完全无存在感，没有持续 Build 的装备感。
2. **“非酋惩罚与鸡肋日用品”**：指甲剪、创可贴、保温杯等毫无剧情质变空间；抽到原生家当（破陶碗）更是纯白板惩罚。
3. **“无脑飞黄腾达或生硬暴毙”**：缺乏策略与运气的交织，要么抽到必赢，要么莫名其妙暴毙。

### 2. 重构核心目标
* **短剧式爽感节奏**：觉醒、破局、传承按入局后的相对年份推进；3–10、11–20、21–45、46+ 使用适龄叙述，不把阶段绑定为绝对年龄。
* **高阶路线策略门槛**：核心道具、特定时局、属性硬门槛、真实策略前置与 D20 检定共同约束突破，不能持卡直接晋升。
* **暗坑与滑稽翻车**：资源有限、时代误会和工具盲区必须有真实后果；危险行动先给退路或进行检定，不用血腥事故和无条件死亡代替失败设计。

## 三、 8 大 Build 深度网状化学反应、高级门槛与暗坑矩阵

### 1. 神农篇：高产耐旱玉米良种

- `CHAIN_MOD_CORN_KING` 在入局后第 1、3、6 年依次试田、合仓、济邻；四段年龄各有互斥的自动开局。主动退出、重伤或流离会中断。
- 1643–1644 年开局在 1644 年依次盘点粮种、分粮、护送；晚开局转入快进后不重复结算原主链。
- `E_MOD_CORN_BREAKTHROUGH` 的历史推广要求年份 ≥1640、才干 ≥12、人脉 ≥8 和试种前置；历史与架空推广均为 `farming` DC20，不另设原骰下限。失败时历史线家资-1、人脉-1，架空线人脉-1；平价接济和退出仍保留。
- `farming` 检定持卡修正 +1；读书、从军、行商和北平历史事件均有实际交叉选项。
- 年满18岁的玩家可自愿冒险送种到邻村；DC16 成功人脉+2，失败仍为 `D_MOD_CORN_THEFT`。旧争辩和卖粮送命选项及其独占阶段已移除，`D_MOD_CORN_RUMOUR`、`D_MOD_CORN_HUNGER` 与原死亡成就保留为历史记录，不挪作新成就。新成就分别以平价接济和推广受挫的真实标记解锁。

### 2. 医圣篇：抗生素与防疫手册

- `CHAIN_MOD_HEALER_SAGE` 在第 1、3、6 年处理用药边界、清洁隔离和救助协作；四段年龄分别有对应开局。
- 1643–1644 年开局在 1644 年进入分诊、净水、救助交接；重伤、道路中断或主动退出会停链。药量有限，不能预防一切感染，也不能独自终结大疫。
- 突破 `E_MOD_HEALER_BREAKTHROUGH` 要求年份 ≥1640 和救助准备；推广照护还需才干 ≥12、人脉 ≥8，`medicine` 检定 DC20、不另设原骰下限。可留在本地、主动交出整板药或退出；未选择交药不会自动交出。
- `medicine` 检定持卡修正 +1；读书、从军、行商、科举后续和北平历史事件均有交叉选项。
- 已移除主动延误求医和独行取药选项；`D_MOD_HEALER_DELAY`、`D_MOD_HEALER_ROBBERY` 与对应旧成就保留原义作为历史记录，新成就记录本地照护与真实交药。

### 3. 捕神篇：手摇发电强光手电

- `CHAIN_MOD_FLASHLIGHT_DETECTIVE` 在第 1、3、6 年搜证、安排巡夜、护送邻里；四段年龄各有对应开局。
- 1643–1644 年开局在 1644 年改走拆穿骗局、排班照路、夜间撤离；重伤、道路封闭或主动退出会中断原链。灯需要人力摇动，不能穿墙或独挡兵马。
- 突破 `E_MOD_FLASHLIGHT_BREAKTHROUGH` 要求年份 ≥1640、完成普通链或快进；查证／查路选项还需人脉 ≥8 和相应才干或体魄 ≥12。历史与架空线的 `night_patrol` 检定均为 DC18，不另设原骰下限；失败人脉 -1。
- `night_patrol` 检定持卡修正 +1；读书、从军、行商、军功后续和北平历史事件均有交叉选项。
- 年满18岁可以自愿独追抢灯贼，成功人脉 +2，失败仍为 `D_MOD_FLASHLIGHT_ROBBERY`；旧吹嘘和失足送命选项已移除，`D_MOD_FLASHLIGHT_CLAIMS`、`D_MOD_FLASHLIGHT_MISSTEP` 仅作历史记录。

三件首发家当各有 11 个独立事件、4–5 个职业／历史交叉选项和 10 个专属成就；成就优先级分布为 3 N、3 R、3 SR、1 SSR。四段年龄为 3–10、11–20、21–45、46+。各自被动只作用于对应标签，修正仍受规则上下限限制；未配置 `raw_minimum` 或 `critical_success` 的旧内容沿用原检定行为。生产属性上限为 20。

当前结构与依赖校验：`npm run validate:content -- --content assets/resources/data/ming_end`；全套回归：`npm test`；类型检查：`npm run typecheck`。

### 4. 账神篇：太阳能简易计算器（SR）

## 五、 底层技术执行准则 (针对 Cocos 3.8.8 与 Engine)

1. **每局选择一件家当**：开局提供三个不同候选，确认后 `player.cards` 只含所选卡；`POOL_NATIVE_LIFE` 总权重为 100。
2. **内容驱动启动主链**：`GameEngine.selectCard` 选择符合持卡、年龄条件的开局事件；普通开局通过 `chain_start` 启链，不按卡 ID 硬编码。第四步五篇的 1643–1644 年开局须明确接受快进，不同时注册常规主链。
3. **晚开局与检定**：条件使用开局 `start_year` 区分 1643–1644 年人群；突破选项连接真实 D20 阶段，支持原骰下限与自然 20 专属结果。预览与结算共用持卡被动和修正上限。

- 本轮指定的六家当普通突破与胶水验样已取消原骰下限，仍受各自真实时局、属性和前置约束；其他未修改的检定沿用各自配置。失败与安全退出不冒充突破成功。

- 每篇成就严格为 3 N、3 R、3 SR、1 SSR，沿用 `priority` 区间与 `category`；胶水／军刀和火机／醒脑油拆分出来的 17 个旧重复成就已归并到各自主卡十件套，并同步生产引用，不保留运行时别名。

## 八、长线突破与第十年后的传承

真实基线暴露的门槛问题是：玉米、医药和手电已完成准备，但随机事件在 1645 年调度前切入架空推演；这三条突破原先仍要求历史线，即使重大抉择名额未用也永远不会出现。例如自然种子 `normal:27` 的玉米在 1651 年准备完成，原版到 1708 年也没有突破；`normal:12` 医药、`normal:29` 手电同样可复现。原因是内容条件，不是新增骰子规则或冷却。

三条突破保留原事件、阶段、选项和成果 ID，继续共用历史重大抉择名额。架空期可延续已有准备：医药沿用非致死照护推广；玉米和手电在原菜单中增加需原有能力门槛的非致死复核选项，失败只损失人脉，不扣家资或体魄。原致死、可能造成贫困的路线仍限历史线，并保留原风险、结果和引用；未用名额不保证一定能达到高阶能力门槛。已消费名额、主动退出或中断而未完成事业不是同一种死区。

仅对玉米、医药、手电已经完成主链或取得对应快进成果、且未主动退出的人，增加各一次的自动经验交接：试田记录、照护分工、巡查证据分别以真实 D20 检查，成功让既有经验与人脉继续发展，失败保留有限的人脉损失。三个事件均要求 `years_elapsed >= 9`，即开局是第一年时不早于第十年；条件由 `calendar_year - start_year` 派生，不写入存档。它们不新增菜单、费用、身份变更或致死效果，也不声称覆盖所有后期需求。

隔离实验使用原引擎、原骰子和原内容，只叠加新事件与派生条件；同一组四策略各100局中，三个突破分别由 12→20、4→8、30→46 局出现，第十年及以后自动交接分别出现 17、17、48 局。全体最长无实质状态进展间隔 P50/P90 仍为 7/11 年；四策略后期零选择率从 78.57%/73.86%/82.02%/80.00% 变为 79.76%/73.86%/82.02%/80.00%。这证明特定已有事业能继续发展，**不能证明后期选择稀疏已普遍解决**。新规则与最终集成后的四策略验收仍须单独执行；完整基线、分母及命令见 [家庭内容交付](家庭内容交付.md#真实仿真基线与复验)。


## 九、本轮后半生承接与选择窗口

第十年后续是已有生活和事业的兑现，不是所有玩家到了老年。开局年为第一年，`years_elapsed >= 9` 开始境遇兑现，`>= 14` 进入结果扩大，`>= 19` 且年龄至少 55 才进入晚景定形。路线按真实家资、身份和明确成果进入，以保留条件与三年候选确认防止小幅波动反复切线；当前具体事件仍按当年的财富、身体和亲友状态分支。既有能力、成果和关系不因路线转换被清空。

六件现代家当的后续优先使用此前真实试田、照护、巡夜、对账、修样和轮值成果；一般需相应主链完成或既有历史节点适配的明确成果，且未主动退出。胶水和折叠刀另可承接已经发生的修补摆件或农具工序，打火机可承接已经发生的分包干料和雨具；即使事业后来中断，也不虚构整个主链完成。物品的材料、燃料与药量限制保持有效；没有新增卡牌成就，也不改变每张卡的稀有度配额。逐卡具体前提、事件和后果见 [家庭内容交付](家庭内容交付.md#家当与前情承接)。
