# 动效与微交互制作规范 (Game Feel & Motion Specification)

本文档规范本项目（历史重开模拟器）在 Cocos Creator 3.8.8 客户端中的动效、缓动节奏（Juice）与微交互设计标准。所有核心动效基于 Tween.js 理论体系与 Cocos 原生 `cc.tween` 架构落地。

---

## 1. 核心设计原则 (Core Principles)

1. **克制与仪式感 (Restraint & Ceremony)**：
   * 本作为文字与卡牌驱动的历史重开模拟器，避免花哨杂乱的粒子轰炸。
   * 动效服务于“命运抉择的沉重感”与“历史事件的冲击力”。
2. **轻量与零额外依赖 (Zero Extra Dependency)**：
   * 禁止额外安装外部第三方动画库（如外部 tweenjs、gsap），必须直接使用 Cocos Creator 3.8.8 内置的 `cc.tween` 体系与 `Easing` 曲线，确保包体小、零冗余主循环。
3. **性能底线 (Performance Baseline)**：
   * 所有涉及透明度渐变的节点，必须挂载 `UIOpacity` 组件，禁止在 Tween 中直接频繁操作 Sprite 的 Color Alpha（避免破坏合批渲染）。
   * 节点销毁或复用前，必须显式调用 `tween(node).stop()` 清理未完成的补间动画，杜绝内存泄漏。

---

## 2. 缓动曲线标准与映射表 (Easing Function Palette)

| 动效类型 | 推荐曲线 | 物理/心理隐喻 | 典型耗时 (Duration) |
| :--- | :--- | :--- | :--- |
| **词条/卡牌抽中亮出** | `backOut` / `cubicOut` | 弹簧张力回弹、纸牌砸落 | 0.30s ~ 0.40s |
| **属性数值涨跌** | `quadOut` (Punch) | 肌肉收缩震颤、心跳波动 | 0.15s ~ 0.20s |
| **危机与暴毙震动** | 阻尼位移衰减 + `sineInOut` | 地震、心慌、惊雷猝死 | 0.20s ~ 0.35s |
| **历史结局朱批盖印** | `bounceOut` | 沉重玉玺下砸、不可逆定论 | 0.40s ~ 0.50s |
| **岁月日志推进滚动** | `quartOut` | 惯性减速、翻阅史书 | 0.25s ~ 0.35s |

## 3. 五大核心交互场景制作规范 (Five Core Scenarios)

### 3.1 词条/卡牌抽取入场 (Card Flip & Pop-in)
* **设计意图**：玩家在抽取天赋或现代遗物词条时，提供沉浸感强的触感与视觉反馈。
* **制作细节**：
  * **砸入弹跳**：卡牌初始 `scale = (0, 0, 1)`，以 `backOut` 放大至 `1.0`（超冲至约 1.08 后归位），耗时 0.35s。
  * **卡牌翻转 (Card Flip)**：
    * 前半段：ScaleX 在 0.15s 内从 `1.0 -> 0`（`cubicIn`）。
    * 翻转中点：切换卡牌背面贴图为正面内容与属性。
    * 后半段：ScaleX 在 0.15s 内从 `0 -> 1.0`（`cubicOut`）。
* **代码范例**：
  ```typescript
  import { tween, Vec3, Node } from 'cc';

  export function playCardPopIn(node: Node, onComplete?: () => void) {
      node.setScale(new Vec3(0, 0, 1));
      tween(node)
          .to(0.35, { scale: new Vec3(1, 1, 1) }, { easing: 'backOut' })
          .call(() => onComplete?.())
          .start();
  }
  ```

---

### 3.2 属性涨跌跳动与滚字 (Attribute Punch & Count-up)
* **设计意图**：文官/流民/行商路线中，金钱、兵力、寿元增减必须有即时反馈，防止玩家忽视关键数值变化。
* **制作细节**：
  * **果冻微震 (Punch Scale)**：数值变动瞬间，节点在 0.08s 内放大 1.25 倍（`quadOut`），紧接着在 0.12s 内恢复 1.0 倍（`quadIn`）。
  * **红绿色标闪烁**：数值上升短暂偏绿，受损/扣除短暂偏红，随后 0.3s 平滑渐变回默认原色。
* **代码范例**：
  ```typescript
  import { tween, Vec3, Node } from 'cc';

  export function playAttrPunch(node: Node) {
      tween(node)
          .to(0.08, { scale: new Vec3(1.25, 1.25, 1) }, { easing: 'quadOut' })
          .to(0.12, { scale: new Vec3(1.0, 1.0, 1) }, { easing: 'quadIn' })
          .start();
  }
  ```

---

### 3.3 暴毙/绝境报警震屏 (Screen Shake & Death Flash)
* **设计意图**：遭遇明末崇祯自缢、甲申国难、瘟疫流民等恶性事件或濒死时，制造紧迫绝望的情绪重击。
* **制作细节**：
  * **屏幕/根容器震动 (Screen Shake)**：不要线性摇晃，采用 4 段快速阻尼衰减震荡（振幅 +8px -> -6px -> +4px -> 0px），单段 0.04s，总耗时 0.16s。
  * **红屏呼吸暗角**：屏幕外层边缘渐变红色遮罩（Vignette），UIOpacity 在 0.2s 内拉至 160，再在 0.3s 内淡出回 0。
* **代码范例**：
  ```typescript
  import { tween, Vec3, Node } from 'cc';

  export function playScreenShake(targetNode: Node) {
      const origin = targetNode.position.clone();
      tween(targetNode)
          .to(0.04, { position: new Vec3(origin.x + 8, origin.y - 4, origin.z) })
          .to(0.04, { position: new Vec3(origin.x - 6, origin.y + 6, origin.z) })
          .to(0.04, { position: new Vec3(origin.x + 4, origin.y - 2, origin.z) })
          .to(0.04, { position: origin })
          .start();
  }
  ```

---

### 3.4 历史评级与结局“朱批盖印” (Imperial Seal Stamp)
* **设计意图**：人生重开终局（如“殉节忠烈”、“乱世枭雄”、“草芥病殁”），呈现终局落定的历史苍凉感。
* **制作细节**：
  * **重物下砸**：印章初始处于极高缩放（`scale = 3.5`），结合轻微倾斜角度（`angle = -8°`）。
  * **撞击回弹**：在 0.4s 内缩放至 `1.0`，采用 `bounceOut` 曲线，模拟木质/玉质大印猛烈下砸在案牍上的重击震颤。
* **代码范例**：
  ```typescript
  import { tween, Vec3, Node } from 'cc';

  export function playStampSeal(sealNode: Node) {
      sealNode.setScale(new Vec3(3.5, 3.5, 1));
      sealNode.angle = -8;
      tween(sealNode)
          .to(0.4, { scale: new Vec3(1, 1, 1), angle: -3 }, { easing: 'bounceOut' })
          .start();
  }
  ```

---

### 3.5 跨年岁月长河事件流平滑滚动 (Timeline Smooth Flow)
* **设计意图**：每年历史演进，新旧事件条目交替滚动，保持阅读连贯性，避免跳帧突兀。
* **制作细节**：
  * 新条目生成在底部，初始 Y 坐标向下偏移 30px，`UIOpacity` 为 0。
  * 0.3s 内向上滑移归位（`quartOut` 高阶减速），同时透明度线性淡入至 255。
  * 滚动视图通过计算自动匀速滑动到底部，确保最新发生的历史事件处于视线焦点。
* **代码范例**：
  ```typescript
  import { tween, Vec3, Node, UIOpacity } from 'cc';

  export function playLogItemFadeIn(itemNode: Node, opacityComp: UIOpacity) {
      const targetY = itemNode.position.y;
      itemNode.setPosition(itemNode.position.x, targetY - 30, itemNode.position.z);
      opacityComp.opacity = 0;

      tween(itemNode)
          .to(0.3, { position: new Vec3(itemNode.position.x, targetY, itemNode.position.z) }, { easing: 'quartOut' })
          .start();

      tween(opacityComp)
          .to(0.3, { opacity: 255 }, { easing: 'quadOut' })
          .start();
  }
  ```

## 4. 调试与落地核查清单 (Checklist)

1. [ ] 是否复用了 Cocos Creator 3.8.8 原生 `cc.tween`？（严禁引入外部 runtime）。
2. [ ] 节点透明度渐变是否使用了 `UIOpacity`？（严禁直接操作材质破合批）。
3. [ ] 涉及列表复用（NodePool / Virtual List）的节点，回收前是否调用了 `Tween.stopAllByTarget(node)`？
4. [ ] 动效总时长是否克制在 0.1s ~ 0.45s 之间？（绝不拖泥带水阻碍核心阅读流程）。
