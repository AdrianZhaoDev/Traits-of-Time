## 本轮后半生内容与待验收

前文的家庭交付与仿真为此前版本记录，不是本轮后半生的验收结论。本轮使用生产目录中的事件及后续窗口，开局年算第一年：`years_elapsed >= 9` 后进入境遇兑现，`>= 14` 进入结果扩大，`>= 19` 且年龄至少 55 才进入晚景定形。少年或壮年也可能因体弱、失业或依赖他人遇到困难，但不会仅因第十年而被称作老人。晚景不是自动终局；仍按实际年龄、身体、资源与关系逐年结算。本轮不新增跳年或年度合并；既有晚开局在同一年发生的多个历史节点保留，不将此说成所有年份都只有一个事件。

路线初次由当时的家资、真实身份及明确成果分类，后续以保留条件和连续三年候选确认变化；进入一条路线不清除已获得的技艺、身份经历、家庭事实或成就。当前事件和兑现分支还核对现实状态。路线互有优先顺序，以下是阅读线索，不是把所有人强分成富贵与贫困：

重大选择仍共享一生预算：开局方向一次、事业转向最多一次、链终点最多两次、重大抉择最多一次。此前已决定或预算耗尽者沿已授权结果继续，不补发第六次；未用转向且条件适用者可在后续窗口真实选择学习、工艺、生计或邻里方向。11–20 岁的既有免费读写／学徒入口保留早期学习机会，成人入口仍可在前期随机出现，不把所有终点机械推迟到第十二年。终点是否适用仍由各自真实条件决定。

### 人工阅读样本与验证状态

- **权势爽感样本（条件满足时）**：既有族老／社区首领等身份，先前议事的次序实际兑现 → 人们拿受损取水路来商量 → 按讨论结果先修难走的一处 → 挑水不必绕远，名册写明共同出力的人 → 后来轮值册公开，接班者知道向谁交接。不是只换铺子留货，也没有自动获取新官职。
- **富足爽感样本**：已有家资并同粮铺有往来 → 不用抢着看货 → 另约定自己方便的送粮时辰 → 货按时送到、核量结账 → 体弱且仍有资源时可商量按自己时辰照料。资源下降时该安排可以缩减，身体限制不会因有钱消失。
- **困顿同情样本**：无钱添衣先买饭 → 旧衣再补 → 缩餐拖久、短工没轮上 → 屋角漏风仍挤着住；若先前有人肯缓收米钱，记得这份善意但欠账仍在。没有把贫困写成偷窃、无耻或必须死亡。
- **普通及关系样本**：分次取粮后掌柜引见卖柴人，家资允许时按需买柴；孩子符合既有出生时间和年龄前提后商量独立，之后自己安顿日用仍互通消息。伴侣、旧友或邻人分支均以各自状态为准。
- **普通体弱与家庭样本**：体魄至多 2、家资 2–5 时，可以按自己的意思安排物件和托人采买；对方按约搭手但不是随叫随到。若后来钱不够，暂停采买而不是自动赊账。原有伴侣仍在时，也可以先商量遇事搭手，之后兑现一次代取已经准备好的家用；若商量的人已离世，则保留失去共同安排的事实，不能冒认新伴侣完成旧约。
- **已有困顿后改善样本**：先前确有缩减口粮、候补短工的经历；如果后来财力实际回到至少 2，短工仍未得到，但可把先前省下的饭食添回一些。记录的是生活改善而不是虚构就业成功，也不保证以后一直宽裕。
