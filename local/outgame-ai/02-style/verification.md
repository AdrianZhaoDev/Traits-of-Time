## 2. 已观察的 A HTML 行为

- 完整游戏名、核心说明、我要穿越、声音、成就、统计及临时进度提示，在两个主视口中可见；未出现横向溢出。
- 首页主按钮高 58 CSS px，三个辅助入口高 46 CSS px，满足本参考的触控高度目标。实际正式画布命中区仍需接入后验证。
- 四个入口逐一真实点击，风格说明弹层均打开、关闭并恢复打开者焦点。它们不是游戏、真实音量或记录功能，没有读写真实存档。
- 在 320、375、414、768 CSS 宽下另做布局测量；这不是四台真实设备的验收。
- 减少动态仿真后没有运行中的动画，预览中没有游戏 runtime、audio／video 元素或存储键。
- 对 A 的静态文字前景与最近不透明背景计算，已测组合的最低对比约 5.32:1。此项不覆盖未来 Canvas 合成、动态背景、所有设备字体或显示屏。
- [A 原始 HTML](bright-options/a-comic.html) 与两张截图未因本次文档批准改写；哈希见 [A 参考清单](bright-options/manifest.json)。

## 4. 后续正式接入验收契约

正式实现须在 390×844、360×640 **实际 CSS 视口**打开真实 Canvas，读取画布矩形与 DPR，检查标题完整换行、所有真实入口、正文／长列表滚动、busy／禁用／选中／焦点、返回后状态与临时人生提示。短屏先减少插画和留白，不缩小文字、按钮或风险说明。

通过真实 Canvas 操作验证开始→身份→三选一→确认，及成就／统计／声音／管理四页／详情／终局各自的返回路径。管理／声音／详情从局内打开时不能改变下层保护画面；不允许说明弹层或假数据代替业务验收。

缺图时 A 的纸底、文字和操作仍可用，启动／失败宿主兜底不依赖素材。声音先有明确生成授权与实际文件，再用真实手势解锁、检查播放推进并由人耳试听；未做的结果如实写未验证。任何新图片、音乐、视频和上传均受供应商及预算／额度授权约束。
